# Rota Única — Android
Versão inicial de testes, privada. Aplicativo Android nativo (Java), mapa osmdroid, dados OSM e fontes públicas. Não é um produto final. Não há fonte validada de fases semafóricas, GTFS, trânsito nacional, preços por posto ou cobertura completa dos radares municipais. Não use como única fonte de sinalização.
A compilação CI gera um APK de teste assinado com chave debug. Sem publicação. Consulte licenças e políticas das fontes antes de distribuição. A infraestrutura pública de rotas/geocodificação é limitada e não tem garantia de serviço.
